## ⚙️ Configure Backend API (Optional)

To connect your backend API:

### 1. Deploy Backend First
Deploy your Node.js backend to Railway, Render, or similar:
- Backend repo: `backend/` folder
- Port: 5000
- Database: MongoDB Atlas

### 2. Get Backend URL
Example: `https://your-backend.railway.app`

### 3. Update Environment Variable
In Vercel Dashboard → Project Settings → Environment Variables:

```
VITE_API_URL = https://your-backend.railway.app
```

### 4. Redeploy
Push any change to trigger redeployment with new API URL:
```bash
git commit --allow-empty -m "Update API URL"
git push origin main
```

## 📞 Support & Troubleshooting

### Live App Not Showing?
1. Try refreshing the page (Ctrl+Shift+R)
2. Check deployment status: https://vercel.com/nishitbhalerao-7784/openskills-oracle/deployments
3. Wait 2-3 minutes for build to complete

### Getting 404 Errors?
- This is normal during build
- Refresh in 1-2 minutes
- Check dashboard for build errors

### Need to Rollback?
1. Go to Deployments
2. Find a previous deployment
3. Click the three-dots menu
4. Select "Promote to Production"

### Custom Domain?
Vercel allows custom domains:
1. Go to Project Settings → Domains
2. Add your domain (example: openskilloracle.com)
3. Update DNS records
