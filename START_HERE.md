## 🛠️ If Something Breaks

### Error: Button doesn't respond
```
Fix: Refresh page (Ctrl+R)
Check: Browser console (F12)
Try: Clear cache and refresh
```

### Error: Can't submit proof
```
Fix: Check backend running (Terminal 1)
Check: http://localhost:5000/health
Try: Restart backend
```

### Error: Profile not loading
```
Fix: Make sure wallet is connected
Try: Refresh page
Check: Backend logs for errors
```

### Error: Animations not smooth
```
Fix: This is normal on slow computers
Try: Close other tabs
Check: Browser is up to date
```
